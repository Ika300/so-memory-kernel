# Comparison with common memory approaches

## Vector search

Vector search finds similar items.

SO Memory Kernel tracks structural recurrence, evidence, and re-activation.

## RAG

RAG retrieves documents for generation.

SO Memory Kernel does not generate answers. It exposes structural memory signals
that another system may use.

## Knowledge graph

Knowledge graphs store entities and relations.

SO Memory Kernel also observes how relation structures repeat, cluster, leave
gaps, and become active again.

## Summarization

Summarization compresses content into shorter text.

SO Memory Kernel preserves traceable structure. It should not replace the source
memory with a compressed paraphrase.

## Agent memory

Many agent memory systems store and retrieve past messages.

SO Memory Kernel focuses on structural persistence: independent evidence,
contextual recurrence, exact Pattern Identity, and Return candidates.
