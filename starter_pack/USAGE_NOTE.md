# Usage Note

This starter pack is included in the public repository as practical support material.

The repository license applies to the code. This folder contains templates, guides, and examples intended to help users inspect RAG retrieval traces locally.

This material is not legal advice, not a compliance audit, and not a guarantee that a RAG answer is correct or incorrect.

Recommended use:

- adapt the templates for your own local evaluation workflow
- keep customer data local unless you have explicit permission to share it
- manually review any client-facing report before delivery
- avoid overclaiming what the analyzer proves
