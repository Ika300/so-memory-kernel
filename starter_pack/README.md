# Local RAG Trace Analyzer Starter Pack v0.1

A practical free starter pack for checking whether a RAG system is seeing independent evidence or repeatedly encountering the same source.

This pack is designed for local use. It does not require customer data to be sent to an external AI service.

## What this pack is

This is a free companion pack for the `so-memory-kernel` GitHub project.

It helps you turn retrieval traces into readable evidence reports.

## Core question

Your RAG may not have more evidence.
It may be seeing the same evidence repeatedly.

This pack helps you inspect that difference.

## Included

- CSV input templates
- Example RAG trace scenarios
- Report interpretation guide
- Client-facing report templates
- Local privacy guide
- Failure pattern guide
- Delivery checklist

## Not included

- No cloud service
- No API key handling
- No customer data upload
- No external AI processing
- No production integration support
- No legal or compliance guarantee

## Recommended workflow

1. Prepare a retrieval trace CSV using the included template.
2. Run the RAG Trace Analyzer from this repository.
3. Read the generated report using the guide in this pack.
4. Copy the useful findings into the client report template.
5. Edit the report manually before sharing it.

## Boundary

The GitHub repository provides the free engine, basic analyzer, and this starter pack.

The starter pack is not a SaaS, not an audit service, and not a correctness guarantee. It is practical support material for local evidence-structure review.
