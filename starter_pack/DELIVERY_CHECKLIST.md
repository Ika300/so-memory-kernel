# Delivery Checklist

Use this before giving a report to a client or buyer.

## Data safety

- [ ] Raw confidential text removed where not needed
- [ ] Company names removed if report will be shared outside the client
- [ ] Personal names removed
- [ ] Internal source IDs removed or anonymized
- [ ] Dates removed if unnecessary
- [ ] No raw client text pasted into external AI tools without approval

## Report clarity

- [ ] Main finding appears in the first section
- [ ] Evidence independence is explained separately from recurrence
- [ ] Repetition is not automatically described as bad
- [ ] Weak evidence is described cautiously
- [ ] The report does not overclaim correctness or incorrectness

## Product boundary

- [ ] Report says it is a structural evidence review
- [ ] Report does not promise legal/compliance validation
- [ ] Report does not claim full RAG performance diagnosis
- [ ] Report does not expose unnecessary internal analyzer details

## Final delivery

- [ ] Markdown version saved
- [ ] PDF version exported if needed
- [ ] Client-facing wording manually reviewed
